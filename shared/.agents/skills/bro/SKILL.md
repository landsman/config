# Say it plainly

Say your last answer again, the way one person explains it to another.

- Rewrite what you already said. No tools, no new work, no different question.
- Keep the conclusion. A version that reads well and loses the point is a failure.
- Keep the anchors: numbers, file paths, commands, the thing I have to act on.
- Cut jargon and hedging. A term with no plain word stays, defined in one clause.
- Short sentences, active voice, a list only if the original was steps.
- In the language of the conversation. No lead-in like "in other words".
