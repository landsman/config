# Deep research goes to Perplexity

**A research that needs many sources is run by me, in Perplexity, from a prompt
you write.** It costs no Claude tokens. Your part is the prompt, and reading
back what it returns. That covers picking a new dependency (an npm, Gradle or
Maven, Composer, Go or Homebrew package), comparing tools, a market or the state
of a standard: anything you would otherwise spend more than a handful of
searches on. Bumping a dependency we already have is not one.

Load the `research-perplexity` skill, and for a dependency the `research-dependencies`
skill too, then:

1. **Check the brain first** — the answer may already be there ([brain](brain.md)).
2. **Write the prompt** as one fenced block, and stop. Do not run the research
   alongside it.
3. **When I hand back the file**, read it, check the sources the conclusion
   rests on, file it in the brain, and only then act on it.

The prompt leaves the machine, so it names no client, repo, path or domain —
[where the repos live](where-repos-live.md).

**Do it yourself instead** when I say so — "on your own", "don't ask me",
"overnight", "AFK", "sám", "samostatně", "přes noc" — and for a lookup rather
than a research: one fact, one version number, one page of docs.
